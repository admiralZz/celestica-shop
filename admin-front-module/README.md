# Admin Shop

Админка для магазина на React с TypeScript, Tailwind CSS и Webpack.

## Установка

```bash
npm install
```

## Запуск для разработки

```bash
npm start
```

### Указать API backend

```bash
REACT_APP_API_BASE_URL=http://localhost:8083/api npm start
```

Приложение будет доступно по адресу [http://localhost:3000](http://localhost:3000).

## Сборка для продакшена

```bash
npm run build
```

Собранные файлы будут находиться в директории `dist`.
