# Online Shop Backend

Бэкенд для интернет-магазина детских игрушек, разработанный на Spring Boot.

## Технологический стек

- Java 17
- Spring Boot 3.4.5
- Spring Data JPA
- H2 Database (для разработки)
- Lombok
- Gradle

## Основные цели проекта

### 1. Управление товарами
- Создание каталога товаров с детальным описанием
- CRUD-операции для товаров
- Категоризация товаров по типам, возрастным группам, образовательной ценности
- Поиск и фильтрация товаров по различным параметрам
- Управление наличием товаров на складе

### 2. Управление пользователями
- Регистрация и авторизация пользователей
- Профили пользователей с сохранением личных данных
- Разграничение прав доступа (роли: клиент, администратор)
- Безопасная аутентификация с использованием JWT-токенов

### 3. Корзина покупок
- Добавление товаров в корзину
- Изменение количества товаров
- Удаление товаров из корзины
- Сохранение корзины между сессиями для авторизованных пользователей

### 4. Оформление заказов
- Создание заказа из корзины
- Выбор способа доставки
- Выбор способа оплаты
- Подтверждение и оформление заказа

### 5. Управление заказами
- Отслеживание статуса заказа (создан, подтвержден, оплачен, отправлен, доставлен)
- История заказов пользователя
- Административный интерфейс для управления заказами

### 6. Платежная система
- Интеграция с платежными шлюзами
- Подтверждение оплаты
- Возврат средств при отмене заказа

### 7. Система отзывов и рейтингов
- Добавление отзывов о товарах
- Оценка товаров по шкале от 1 до 5
- Модерация отзывов

### 8. Аналитика и отчеты
- Сбор статистики продаж
- Выявление популярных товаров
- Формирование отчетов о доходах и активности

## План разработки MVP (минимально жизнеспособный продукт)

1. **Этап 1: Базовая инфраструктура**
   - Настройка проекта Spring Boot
   - Настройка базы данных
   - Настройка Spring Security

2. **Этап 2: Управление товарами**
   - Модели данных для товаров и категорий
   - REST API для CRUD операций с товарами
   - Поиск и фильтрация товаров

3. **Этап 3: Пользователи и авторизация**
   - Регистрация и вход пользователей
   - JWT авторизация
   - Профили пользователей

4. **Этап 4: Корзина и заказы**
   - Функционал корзины
   - Создание и управление заказами
   - История заказов

5. **Этап 5: Расширенный функционал**
   - Система отзывов
   - Интеграция с платежными системами
   - Аналитика продаж

## Запуск проекта

```bash
# Клонирование репозитория
git clone [URL репозитория]
cd online-shop

# Запуск приложения
./gradlew bootRun
```

Приложение будет доступно по адресу: `http://localhost:8083`

## API Endpoints

- `GET /api/products` - получение списка всех товаров
- `GET /api/products/{id}` - получение информации о конкретном товаре
- `POST /api/products` - добавление нового товара (требуется авторизация)
- `PUT /api/products/{id}` - обновление информации о товаре (требуется авторизация)
- `DELETE /api/products/{id}` - удаление товара (требуется авторизация)
- `POST /api/auth/register` - регистрация нового пользователя
- `POST /api/auth/login` - вход в систему
- `GET /api/cart` - получение содержимого корзины
- `POST /api/cart/items` - добавление товара в корзину
- `DELETE /api/cart/items/{id}` - удаление товара из корзины
- `POST /api/orders` - создание нового заказа
- `GET /api/orders` - получение списка заказов пользователя
